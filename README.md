# داشبورد مدارک نیروگاه‌های خورشیدی

این داشبورد فارسی، وضعیت ۴۶۲ مدرک در ۹ نیروگاه را از فایل‌های اکسل MDL می‌خواند و تغییرات وضعیت و تاریخ آخرین تغییر را در همان فایل‌ها ذخیره می‌کند.

## اجرا

در Windows با Microsoft Excel نصب‌شده، فایل [start-dashboard.cmd](start-dashboard.cmd) را اجرا کنید. مرورگر در نشانی `http://localhost:18765/` باز می‌شود. پنجره PowerShell را تا زمان استفاده باز نگه دارید؛ با بستن آن ارتباط با اکسل قطع می‌شود.

اگر فایل‌ها را از GitHub دریافت کرده‌اید، ابتدا ۹ فایل `* MDL.xlsx` را کنار `server.ps1` قرار دهید. فایل‌های اصلی اکسل در مخزن Git قرار ندارند.

## همگام‌سازی

- تغییر وضعیت یا تاریخ در داشبورد، همان ردیف فایل اکسل مربوط را ذخیره می‌کند. تاریخ با رقم‌های فارسی در ستون «آخرین تغییر وضعیت» ثبت می‌شود.
- اگر وضعیت را مستقیماً در Excel تغییر می‌دهید، تاریخ همان ردیف را هم به‌روز کنید.
- پس از ویرایش اکسل، فایل را **ذخیره کنید**. داشبورد معمولاً ظرف حدود ۷ ثانیه تغییر را می‌خواند؛ دکمه «تازه‌سازی از اکسل» نیز در دسترس است.
- هنگام ویرایش از داشبورد، فایل اکسل مربوط باید برای ویرایش در Excel باز نباشد. اگر فایل قفل باشد، داشبورد پیام خطا می‌دهد و داده را بازنویسی نمی‌کند.
- تاریخ را به صورت شمسی، مانند `۱۴۰۵/۰۷/۲۶` وارد کنید. تغییر وضعیت از داشبورد تاریخ قبلی را پاک می‌کند تا تاریخ وضعیت جدید ثبت شود.
- برای هر مدرک، تاریخ را در کادر همان ردیف وارد کنید و دکمه «ثبت» را بزنید. کلید Enter یا خروج از کادر نیز تاریخ را ذخیره می‌کند. تاریخ‌هایی که سابقه‌ای برای آن‌ها نداریم خالی می‌مانند.
- باز کردن مستقیم [index.html](index.html) یک نمای آفلاین و فقط خواندنی از [data.js](data.js) نشان می‌دهد. برای ارتباط دوطرفه با اکسل، از راه‌انداز بالا استفاده کنید.

فایل `Natanz MDL.xlsx` دارای دو برگه است؛ برای نطنز فقط `Sheet2` استفاده می‌شود، چون `Sheet1` فهرست شهرضا است و شهرضا فایل مستقل دارد. مدارک بدون علامت وضعیت با وضعیت «نامشخص» نمایش داده می‌شوند.

## مدارک تأییدنشده با تأخیر بیش از یک هفته

بخش «مدارک تأییدنشده با گذشت بیش از یک هفته» برای هر نیروگاه فهرست جداگانه‌ای دارد. هر مدرکی که وضعیتش «تأیید شده» نباشد و تاریخ آخرین تغییر وضعیت آن به تقویم شمسی قدیمی‌تر از هفت روز پیشِ امروز تهران باشد، همراه با وضعیت و تاریخ نمایش داده می‌شود. تاریخ دقیقاً هفت روز پیش هنوز در فهرست قرار نمی‌گیرد؛ مدارک بدون تاریخ یا با تاریخ نامعتبر نیز تا ثبت تاریخ معتبر در این فهرست نمایش داده نمی‌شوند. این بخش پس از ذخیره تغییرات داشبورد یا بارگذاری تغییرات Excel به‌روز می‌شود.

## قالب ستون تاریخ در اکسل

در هر ۹ فایل اکسل این پوشه، ستون «آخرین تغییر وضعیت» با سرستون سرمه‌ای، راهنمای تاریخ شمسی و خانه‌های سبز روشن افزوده شده است. در فایل نطنز هر دو برگه قالب‌بندی شده‌اند. برای اعمال همین قالب به مجموعه دیگری از فایل‌های MDL، اجرا کنید:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -STA -File .\style-excel-dates.ps1
```

این اسکریپت پیش از ویرایش، یک نسخه پشتیبان از هر فایل در پوشه `workbook-backups` می‌سازد.

برای ساخت دوباره نمای آفلاین از فایل‌های اکسل، در PowerShell اجرا کنید:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\refresh-data.ps1
```
